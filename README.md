# Java Calendar GUI

## Beschreibung

Dieses Projekt ist ein einfacher Kalender mit einer grafischen Benutzeroberfläche (GUI), der mit Java erstellt wurde. Er ermöglicht grundlegende operationen wie Terminierung, Änderung und Erinnerung.

## Funktionen

* Einfache und benutzerfreundliche GUI.
* Grundlegende Operationen.
* Hinzufügen von Daten.
* Änderung von Daten.
* Einbindung eines Hintergrundbildes.
